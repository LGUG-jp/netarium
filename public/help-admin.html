保存・管理の操作ガイド

データの自動保存の仕組み、他利用者との更新競合の解消、CSV取込・バックアップ復元の使い分け、および利用者・パスワード管理の手順を説明します。

変更の保存と競合への対処

Netariumでは、編集内容を確定（「適用」）すると自動的にサーバーへ保存されます。

  • 自動保存の契機: 機器・接続・メモ・図面の移動や追加は操作確定時に即時自動保存されます。個票やプロパティパネルでの入力は、パネル内の「適用」を押した時点で保存対象になります。
  • 上部バー「保存」ボタン: 未送信の変更がある場合や、通信一時切断後の再試行に使用します。未適用の入力は確定されません。
  • 未適用入力の保護: 個票を閉じたり別の機器を選択した際に未適用入力がある場合、「適用」「編集を続ける」「変更を取り消す」の確認ダイアログが表示されます。
データの競合（コンフリクト）について: 別の利用者が同じ機器やビューを先に更新していた場合、自動上書きを防止するため「競合あり」となります。必要な入力内容をメモ等に控えた上で、画面の「競合した機器を再読込」または「競合したビューを再読込」を実行して最新データを取得し、再度編集を行ってください。

CSVとバックアップZIPの使い分け

機器台帳の外部編集・一括登録にはCSV、システム全体の保全・復元にはバックアップZIPを使用します。

種別対象データ主な用途と制約
機器台帳CSV 機器の基本属性、管理IP、追加IP（JSON形式）。 表計算ソフト等での一括編集・棚卸し用。ビュー配置、接続線、図面、画像、利用者は含みません。新規機器は未配置で取り込まれます。
構成情報ZIP（Web版） 台帳、ビュー、配置、ラック、接続、系統、メモ、変更履歴、各機器の直近1世代Config、画像参照メタデータ。 管理画面の「バックアップ」から取得・復元。画像実体や利用者アカウントは含みません。復元前には必ず退避バックアップを取得してください。
完全バックアップ（サーバーCLI） SQLite DB、画像実体、利用者アカウント。セッションは含めず、復元時に既存セッションを失効させます。 サーバー障害やシステム移行時の全損復旧用。サーバー上でbackup-full.ps1等の管理者スクリプトを実行します。

CSV取込の手順

  1. 機器台帳で「CSV出力」を行い、最新フォーマット（固定20列、UTF-8）のテンプレートを確認します。
  2. 編集後、「CSV取込」でファイル（2MiB・5,000行以下）を選択し、検証結果プレビューを確認します。
  3. 新規機器の件数、更新機器の変更前後、IP重複の警告を確認し、「取込を実行」を押します。

新たに診断するIP重複が1,000組を超える場合は取り込めません。重複するIPを整理するか、CSVを分割してください。

利用者管理とパスワード

管理者は上部バーの「管理」→「利用者管理」から、ユーザーの登録・権限変更・停止・復元を行います。

  1. 新規登録: 「＋ 利用者を登録」を押して登録フォームを展開し、ユーザー名（半角英数3〜50文字）、役割（管理者／閲覧者）、仮パスワードを入力して「利用者を登録」を押します。
  2. 停止・再開（有効/無効）: 一覧で対象利用者の「有効」チェックボックスを切り替え、下部の「適用」を押して確定します。停止前のセッションは再開しても復活しないため、利用再開時は改めてログインしてください。
  3. 削除と復元: 「削除」を押すと削除済みタブへ移動します（操作履歴やデータ整合性を保つため論理削除）。「削除済み」タブで「復元」を押すと一覧へ戻ります（復元直後は無効状態のため、有効にチェックを入れて「適用」で再開します）。
  4. パスワード再設定: 利用者がパスワードを忘れた場合、一覧の「パスワード再設定」から仮パスワードを再発行します。
パスワード要件仕様と制限
文字数 12〜128文字（Unicodeコードポイントで判定）。UTF-8で最大512バイト。
文字種 英大文字・小文字・数字・記号・日本語・絵文字・空白を使用可能（特定の混在は必須ではありません）。
安全基準 頻出・既知漏えいパスワードや、ユーザー名から推測しやすい値は自動的に拒否されます。

仮パスワードで初めてログインする

管理者に登録された新規利用者や、パスワード再設定を受けた利用者は、初回ログイン時にパスワード変更が必須となります。

  1. 管理者から通知されたユーザー名と仮パスワードでログインします。
  2. 初回パスワード変更画面が表示されるので、仮パスワードと「新しいパスワード（12文字以上）」を入力します。
  3. 「パスワードを変更」を押すとログアウトします。
  4. 新しいパスワードで再ログインすると、通常の管理画面が利用可能になります。
