# スクリプト一覧

Netarium の運用、保守、開発、試験で使用するスクリプトの一覧です。
実行区分と権限に応じて分類しています。

日常の運用手順は [クイックスタート](../docs/quickstart.md) および各詳細ガイドを参照してください。
内部共通部品に分類されているスクリプトは他のスクリプトから呼び出されるため、単体で直接実行しないでください。
配備・運用用 PowerShell スクリプト（`*.ps1`）は、Windows PowerShell 5.1（日本語 Windows Server／CP932）環境での文字コード誤認や改行破損を防止するため、純粋な ASCII（BOMなし）で構成されています。

## 導入・更新・撤去・セキュリティ確認

新規導入、バージョン更新、環境撤去、配備後のセキュリティ確認で使用するスクリプトです（計 5 件）。

| ファイル名 | 種別 | 対象読者・必要権限 | 用途 | 影響・注意事項 | 詳細手順 |
|---|---|---|---|---|---|
| `setup-iis.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | IIS、FastCGI、PHP の新規環境構築および設定の再適用 | Web サイトやアプリケーションプールの作成と設定変更を実施。既存設定の上書きやサービス停止を伴う場合があるため、実行前に設定値を確認する | [クイックスタート](../docs/quickstart.md#1-インストール新規導入)、[配備ガイド](../docs/deployment.md#2-配備を実行する) |
| `update.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | 既存の Netarium 環境の新バージョンへの更新 | アプリケーションプール停止と接続ドレインを伴いサービスが一時停止する。更新失敗時は自動でロールバックを実行する | [クイックスタート](../docs/quickstart.md#2-アップデートバージョン更新)、[更新ガイド](../docs/update.md#更新手順) |
| `uninstall-iis.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | IIS からの Netarium 環境の撤去 | 破壊的操作。Web サイトとアプリケーションプールを削除する。`-RemoveData` 指定時はデータベースや画像実体も削除するため、事前にバックアップを取得する | [クイックスタート](../docs/quickstart.md#5-アンインストール環境の撤去)、[運用ガイド](../docs/operations.md#アンインストール) |
| `verify-security.ps1` | 管理者が実行する入口（検証） | サーバ管理者 | 配備済み Web サイトのセキュリティ設定検証 | 読み取り専用の HTTP 検査リクエストを送信する。非公開ファイルへのアクセス遮断や機密文字列の非露出を確認する | [配備ガイド](../docs/deployment.md#セキュリティ確認) |
| `check-install.php` | 管理者が実行する入口（点検） | サーバ管理者 | PHP 拡張モジュール、設定値、権限、データベース接続の健全性点検 | サービス停止は行わないが、DB 未初期化時はスキーマ初期化・マイグレーションが実行される場合がある。CLI SAPI 専用 | [配備ガイド](../docs/deployment.md#cli確認)、[手動配備ガイド](../docs/deployment-manual.md) |

## バックアップ・復元・管理者復旧

データの保全、復元、および緊急時の管理者復旧で使用するスクリプトです（計 4 件）。

| ファイル名 | 種別 | 対象読者・必要権限 | 用途 | 影響・注意事項 | 詳細手順 |
|---|---|---|---|---|---|
| `backup-full.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | 停止型完全バックアップアーカイブ（ZIP）の作成 | 接続ドレインとアプリケーションプール停止を伴いサービスが一時停止する。ローカル固定ディスクの絶対パスが必要 | [クイックスタート](../docs/quickstart.md#3-バックアップデータの保全)、[運用ガイド](../docs/operations.md#停止型完全バックアップの仕様と取得手順) |
| `restore-full.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | 完全バックアップアーカイブ（ZIP）からの復元 | 破壊的操作。既存のデータベースと登録画像をバックアップ内容で上書きする。サービス停止を伴うため、事前に現行データの退避を推奨する | [クイックスタート](../docs/quickstart.md#4-リストアデータの復元)、[運用ガイド](../docs/operations.md#停止型完全復元の仕様と全損復旧手順) |
| `recover-admin.php` | 管理者が実行する入口（緊急復旧） | サーバ管理者（ローカル権限） | 全管理者がログイン不能となった場合の緊急復旧 | admin アカウントの認証情報を直接更新する。管理画面が利用可能な通常時は使用せず、管理画面から操作する | [管理者ガイド](../docs/administrator-guide.md#adminの緊急復旧) |
| `issue-bootstrap-secret.php` | 管理者が実行する入口（初期導入用） | サーバ管理者（管理者権限） | 初回管理者登録用の一時シークレット発行 | 初期管理者が未作成の状態でのみ機能する。出力先ファイルは Web 非公開の保護ディレクトリに配置する | [配備ガイド](../docs/deployment.md#3-初期管理者を作成する) |

## パスワード辞書・保守

追加パスワード禁止辞書の管理および定期保守で使用するスクリプトです（計 4 件）。

| ファイル名 | 種別 | 対象読者・必要権限 | 用途 | 影響・注意事項 | 詳細手順 |
|---|---|---|---|---|---|
| `set-password-blocklist.ps1` | 管理者が実行する入口 | サーバ管理者（管理者権限） | 追加パスワード禁止辞書の登録および無効化 | ストレージ領域への辞書配置とアプリケーションプール権限設定を実施する。登録前に辞書形式を検査する | [運用ガイド](../docs/operations.md#任意追加辞書) |
| `password-blocklist.php` | 開発・検証用／管理者が実行する入口（検証） | サーバ管理者・開発者 | 追加パスワード辞書ファイルの構文、行数、容量上限の単体検証 | 検査のみを実施し、システム変更は行わない。`set-password-blocklist.ps1` からも呼び出される | [運用ガイド](../docs/operations.md#任意追加辞書) |
| `prune-audit-logs.php` | 管理者が実行する入口（定期保守） | サーバ管理者 | 保存期間（90 日）を超過した監査ログの整理・削除 | 期限切れログが削除される。長期保管が必要なログは事前に退避する。タスクスケジューラ等で定期実行する | [運用ガイド](../docs/operations.md#監査ログ運用) |
| `prune-restore-previews.php` | 管理者が実行する入口（定期保守） | サーバ管理者 | 期限切れの復元プレビュー作業ファイルの回収・削除 | 期限切れの一時展開データのみを削除し、本番データには影響しない。排他ロックを獲得して処理する | [運用ガイド](../docs/operations.md#復元プレビューの保持上限と回収197) |

## 内部共通部品

他のスクリプトから呼び出される共通処理です（計 4 件）。
単体での直接実行は想定していません。

| ファイル名 | 種別 | 対象読者・必要権限 | 用途 | 影響・注意事項 | 詳細手順 |
|---|---|---|---|---|---|
| `deployment-common.ps1` | 内部ヘルパー | 内部呼出専用 | 配備、更新、撤去スクリプトの共通定数、パス検証、IIS 操作関数 | 単体で直接実行しない。各管理スクリプトからドットソースで読み込む | [配備ガイド](../docs/deployment.md) |
| `full-backup-common.ps1` | 内部ヘルパー | 内部呼出専用 | バックアップおよび復元の共通プロセス制御、排他ロック、パス検証 | 単体で直接実行しない。`backup-full.ps1` や `restore-full.ps1`、`update.ps1` から読み込む | [運用ガイド](../docs/operations.md#停止型完全バックアップの仕様と取得手順) |
| `full-backup-helper.php` | 内部ヘルパー | 内部呼出専用 | バックアップおよび復元の SQLite 整合性検査、ZIP 展開、ファイル配置 | 単体で直接実行しない。PowerShell スクリプトから JSON RPC ワーカーとして呼び出される | [運用ガイド](../docs/operations.md#停止型完全バックアップの仕様と取得手順) |
| `iis-lifecycle-state.ps1` | 内部ヘルパー | 内部呼出専用 | IIS 構成状態の取得およびフィンガープリント計算 | 単体で直接実行しない。ライフサイクル試験スクリプト等から呼び出される | [開発ガイド](../docs/development.md#配備スクリプトの確認) |

## 開発・試験・公開候補生成

|---|---|---|---|---|---|
| `run-tests.ps1` | 開発・検証用 | 開発者・検証担当 | API 回帰テストスイートの一括実行 | 一時ディレクトリおよび一時 SQLite データベースで検証するため、本番環境に影響しない | [テストガイド](../tests/README.md#1-概要と実行方法)、[開発ガイド](../docs/development.md#実行方法) |
| `test-iis-lifecycle.ps1` | 開発・検証用 | 開発者・検証環境管理者 | 隔離環境での IIS 配備、更新、撤去、ロールバックの自動検証 | 破壊的検証を含むため本番機では実行不可。`-AllowDestructive` および `-ConfirmTarget` の明示指定が必須 | [開発ガイド](../docs/development.md#配備スクリプトの確認) |
