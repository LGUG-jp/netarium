# Netarium v2.0.1 リリースノート

v2.0.1 は、v1.5.2 に続く公開版です。
建物ビュー、共通接続、ポート単位の VLAN 管理など、v2.0 系の主な変更は [v2.0.0 リリースノート](release-notes-v2.0.0.md) を参照してください。

## v2.0.1 の修正

公開リポジトリの CI が、公開済みコミットの SHA を非公開参照として誤検知する問題を修正しました。
v2.0.0 からアプリの動作、DB スキーマ 29、Web 構成情報 ZIP と停止型完全バックアップ ZIP の形式 1 は変わりません。

## v1.5.2 からの更新

中間版を導入せず v2.0.1 へ直接更新できます。
更新前に停止型完全バックアップを取得し、[更新・ロールバックガイド](update.md) または [Docker 配備・運用ガイド](deployment-docker.md) に沿って作業してください。
