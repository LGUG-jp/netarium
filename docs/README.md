# Netarium文書案内

導入・更新・運用の手順と、開発・試験・設計記録を分けて管理します。現在のバージョンと機能概要は[プロジェクトREADME](../README.md)、版ごとの変更は[変更履歴](../CHANGELOG.md)を参照してください。

## 導入・更新・運用

| 目的 | 文書 | 対象と範囲 |
|---|---|---|
| 基本的な運用操作を素早く把握する | [クイックスタートガイド](quickstart.md) | サーバ管理者向け。インストール、アップデート、バックアップ、リストア、アンインストールの5操作を簡潔に解説 |
| 初めてインストールする | [配備ガイド](deployment.md) | サーバ管理者向け。Windows Server・IIS・PHPの準備、新規配備、初期管理者作成、導入後の確認、setup再実行 |
| 配備済み環境を新版へ更新する | [更新ガイド](update.md) | サーバ管理者向け。更新の前提、保守状態、更新、確認、失敗時のロールバック。旧配置からの自動移行は対象外 |
| 画面操作・利用者管理を確認する | [管理者ガイド](administrator-guide.md) | アプリ管理者向け。日常の画面操作、権限、利用者管理、adminの緊急復旧 |
| サーバを保守・復旧・撤去する | [運用ガイド](operations.md) | サーバ管理者向け。バックアップ保管、ログ保守、全損復旧、アンインストール |
| 自動setupを使用せず新規配備・再構築する | [手動配備・全損復旧ガイド](deployment-manual.md) | サーバ管理者向けの代替手順。既存環境の更新・旧配置からの移行には使用しない |

基本的な運用手順は[クイックスタートガイド](quickstart.md)で確認し、詳細なパラメータや前提条件、代替手順は各詳細ガイド（[配備ガイド](deployment.md)、[更新ガイド](update.md)、[運用ガイド](operations.md)、[手動配備・全損復旧ガイド](deployment-manual.md)）を参照してください。実環境での確認は、開発ガイドの「配備スクリプトの確認」に従います。

## 構造・設計記録

- [Netariumについて](about.md): プロダクトコンセプト、名称の由来、想定利用者、ロゴ・サービスマークの意味と使い分け。
- [デザインガイドライン](design-guidelines.md): UI設計の基本方針、画面要素と情報階層、操作語彙ルール、ボタン階層、セマンティックカラー規律、アイコン資産管理。
- [アーキテクチャ](architecture.md): 現在の構造、データモデル、認証、保存・配備の境界。
試験の実行結果、未実施項目、個別の障害はIssue・Pull Requestへ記録します。ガイドには再利用する手順と注意事項を置き、特定の試験結果を現在の環境に対する保証として扱いません。
